# TalentPulse AI 🚀

*TalentPulse AI* is a smart web application built with Streamlit for the *Anna AI OS Founding Builder Challenge 2026 (Anna AI App Builder Challenge 2026)*. It helps students and job seekers prepare for technical interviews by scanning resumes for ATS (Applicant Tracking System) scoring and conducting real-time AI mock interviews.

## 🏆 Hackathon / Challenge Submission
- *Event:* Anna AI OS Founding Builder Challenge 2026
- *Category:* AI Engineering
- *Objective:* Helping students analyze their resumes and practice technical interviews using AI.

## ✨ Features
- *ATS Resume Analyzer:* Scans resumes to provide an ATS compatibility score and actionable feedback.
- *AI Mock Interviews:* Conducts real-time technical interview sessions tailored to your resume.
- *Interview Prep:* Helps students identify skill gaps and crack technical rounds effectively.

## 🛠️ Tech Stack
- *Frontend & Backend:* Streamlit (Python)
- *AI Integration:* LLM API (OpenAI / Gemini)

## 🚀 How to Run Locally

1. *Clone the repository:*
   bash
   git clone https://github.com
   cd Talentpulse-ai
   

2. *Install dependencies:*
   bash
   pip install -r requirements.txt

3. *Run the Streamlit app:*
   bash
   streamlit run app.py
